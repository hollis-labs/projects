# Agent Workspace

Skills and commands symlinked from `~/Projects-apps/agentrc/`.
See `agentrc/docs/agent-framework-v2.md` for the design guide.

## Rules
- If `boot-prompt.md` exists, read it first for session context.
- Do not guess when uncertain. Stop and ask for clarification.
- Prefer focused, minimal output. No trailing summaries.
- Sub-agent output stays in the sub-agent. Main context gets one-line confirmations.
