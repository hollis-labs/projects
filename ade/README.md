# ade

Applications composed from the ADE packages (`@hollis-labs/ade-core`, `ade-agent`,
`ade-react`, in hollis-labs/frontend-support under `ts/ade`) and the embedded agent host
(`github.com/hollis-labs/libs/agent/host`). They are examples of the interaction, kept here
while it is decided which survive.

- `chess-tutor/`: a board, a guide and a tutor over one game.
